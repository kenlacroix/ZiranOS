Walkthrough (spoilers)

The layout

On upload the server builds one buffer: [ your image (N bytes) | your flag (64) ]. You're told the disk is only your N bytes — but the whole buffer is mounted, and the flag sits at exactly [N, N+64).

The bug

The reader believes the total_size in your header instead of the real buffer length, and leaves extents unconfined. So a file entry with offset = N, length = 64 passes validation and reads straight into the appended flag — bytes you never uploaded. "Validating against a length the caller supplies is not validation."

By hand
